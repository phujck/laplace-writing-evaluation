# Publish and recover exact Source meaning

This explicit optional example constructs one authored public retained fact with an identity metric and real local CUDA embeddings. It then retains a Work handoff's declared authority segment, prepares and commits that exact Source contribution, reads its published counterpart, and recovers its facts through both the owner and engine typed-descent routes. The unselected retained node and vector remain unchanged.

The case records refusal for native publication authority, an incorrect parent, changed base artifacts, a foreign read scope and an unavailable historical publication. Completed replay has no new journal or publication effect. After a source comment changes the file's bytes, the original published facts remain recoverable and fresh preparation reports the unchanged consumed meaning as `CARRIED`.

This demonstrates actual implementation behaviour over a small public fixture. The retained base and identity metric are explicit inputs, not metric-quality or full-world-fold evidence. The native publication verifier, device guard, scope checks and recovery owners execute unchanged. It makes no generative provider call and reads no private author state.

## Explicit prerequisites

Use an already provisioned Python runtime with the package's GPU dependencies and a working CUDA embedding provider. The default CPU examples remain usable separately. Active Source publication currently requires the native GPU path and refuses CPU substitution.

Supply locally built Laplace and Atlas wheels and an already-local public `fast-bge-small-en-v1.5.tar.gz` model archive. No weights are included or downloaded by this example. The runner installs only the two supplied wheels, with no dependency resolution or network, into the new fixture's `workspace/src` target. This is an explicit wheel installation in the layout expected by the current native lifecycle owner. The `--configure-runtime` option authors the observed interpreter/version into the new fixture's public lifecycle template; it changes neither the package nor its runtime guard.

For example, build wheels offline in a separate scratch copy of the public candidate:

```sh
python -s -m pip wheel --no-index --no-deps --no-build-isolation \
  --wheel-dir /absolute/scratch/wheels /absolute/candidate /absolute/candidate/atlas
```

Then run with a new output outside any Git checkout:

```sh
python -s -B /absolute/candidate/examples/run_source_publication.py \
  --candidate-root /absolute/candidate \
  --output /absolute/new-public-source-run \
  --laplace-wheel /absolute/scratch/wheels/laplace_engine-0.1.0-py3-none-any.whl \
  --atlas-wheel /absolute/scratch/wheels/atlas-0.1.0-py3-none-any.whl \
  --model-archive /absolute/local-public-model/fast-bge-small-en-v1.5.tar.gz \
  --configure-runtime
```

The output must not exist. The example creates its own home, state, cache, workspace and evidence. It blocks remote network access and verifies every loaded Laplace/Atlas module's installed origin. Existing runtime dependency packages are used in place; no global environment or Main source is changed. A missing optional capability is reported rather than represented as an executed publication.

## Read the result

`evidence/source-publication-summary.json` gives the actual outcome. `publication-commit.json` contains the native publication handle, device, metric and changed-artifact receipt. `publication-counterpart.json`, `publication-recovered.json` and `publication-engine-descent.json` show the positive read paths. The refusal receipts and replay/source-move receipts expose their exact inputs and outcomes. `installed-bootstrap.json` records both wheel hashes, the supplied model hash and explicit runtime configuration. `module-origins.json` supplies the package-origin audit.

The initial `source_kernel` group deliberately reports the preparation stage as `UNRESOLVED`. The subsequent `source_publication` group supplies the separate real `RECORDED` → `PUBLISHED` → `RECOVERED` result. Preparation alone remains accurately labelled. These are finite implementation examples, not manuscript review, scientific acceptance or an authored sewup.
