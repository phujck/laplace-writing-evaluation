When the codec rebuilds an object one grade at a time, perfection is not the aim. What matters is
that whatever is left over after a pass is contained enough to wrap up the current level and hand a
foothold to the level above. So the question to ask is no longer "how close is the copy" but "can
the leftover be carried forward" — a reconstruction that fails only in ways the next, finer pass can
pick up is exactly what we want, not a disappointment. Loss that is mere scatter, going nowhere, is
the genuine failure. And because a leftover that truly feeds the next stage cannot be counterfeited,
this test resists gaming better than a similarity score does.
