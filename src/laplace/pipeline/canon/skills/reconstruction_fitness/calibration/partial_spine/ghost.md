The halt rule estimates a contraction rate from how the lost set changes between cycles and checks
it against a target that depends on the node. If the loop has settled into the stable basin with a
good reconstruction, it is converged-faithful. If it has settled but the content is confabulated,
that is the degenerate case — a plateau you climb out of by going up a grade rather than grinding it
down. If the rate is at or above one, or the loop is going in circles, it is oscillating. Otherwise
it is still open. The target rate differs by the kind of node.
