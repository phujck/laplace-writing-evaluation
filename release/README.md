# Selected evaluation contents

This is a curated fresh-root repository, not a copy of the author's full project database. `selection-manifest.json` pins copied source bytes and the four canonical manuscript build closures. Registry entries are derived to select those sources without importing private project metadata or author sessions. No author conversation or Work history is fabricated; new authoring state is local.

The existing full exporter and verification scripts remain available for future explicitly reviewed project exports. This hand-curated distribution does not claim to satisfy their historical complete-ledger export contract. It carries no synthetic author history or substituted acceptance records.

Excluded: original Git history; private intake/correspondence and report responses; the archived recipient-specific due-diligence edition; private project notes and session ancestry; personal profile records and `soul`; provider authentication/transcripts; runtime state/cache; host-specific reader qualification. No directory-wide clearance is inferred from including a current manuscript.

The four canonical manuscripts include the completed common editorial pass and verified final build outputs, recorded in [paper-builds.json](paper-builds.json). Application sources include the adopted visual-reader repair. [Scientific evidence paths](../docs/evaluation-scientific-evidence.md) connect the manuscripts to retained results and method code. The exact final distribution pins are in the selection manifest.
