# Start here

Read, write and organise a project. AI help is optional.

## Choose a start

Start with Projects. Each project keeps related writing, sources, tasks and conversations together; reading and writing need no Task.

Reading and manual writing need no AI account. Asking an AI needs a configured provider and an explicit Send.

1. Write: open or create an Article or Book, then Writing.
2. Read: open a project, then Sources and Add local document.
3. Organise: open Tasks; read the purpose, state and next action.
4. Continue: use Home or Recent activity. Open a task and What led here to find its actual results.

## Keep your place

Help explains this screen; recipes show routes, the glossary explains states, and advanced reference names detailed guides.

A completed task can need current review or lack supporting raw; its achievement stays recorded.

Looking elsewhere never sends or retargets a message. Inspect context before Send; check an uncertain original request before trying again.
