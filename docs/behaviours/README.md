# Running the owner examples

Use the Python environment into which the public candidate was installed. Do not use Main's checkout launcher or its state. Set `SITE` to that installation's package parent, normally the environment's `site-packages`.

```sh
python -B -s examples/run_behaviours.py --package-root "$SITE" --output /absolute/new/example-run
```

The output must be new or empty. The driver refuses a nonempty destination, checks package origins, replaces inherited application/home/cache/state coordinates, removes credentials from the environment and permits only loopback network connections in its own process. It does not call a model. All owner calls receive the explicit generated workspace. This is an offline workflow example, not an operating-system sandbox for arbitrary untrusted plugins.

The default finite run creates one readable project, an authored definition, a Work item, reader plans, owner-custodied artifacts, a deterministic arithmetic run/result, a local synthetic original/read/bind, source history with an issued undo, Atlas events and an exact-byte snapshot. It also starts the existing application on ephemeral loopback for source Save/reopen and Work guards, then stops it. Nothing is copied from historical conversations. Inspect `evidence/summary.json`, every domain result, `module-origins.json` and the actual workspace records. An assertion or owner failure remains FAILED with its traceback and preceding receipts.
