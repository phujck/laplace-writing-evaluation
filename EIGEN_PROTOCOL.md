# Standalone Writing distribution protocol

This checkout contains application source, explicitly selected project records and reproducible examples. Read AGENTS.md and README.md first. It does not contain the original author's private persona, shared-home memory or credentials.

Use an explicit checkout/state root and the local runtime setup described in docs/evaluation-dependencies.md. Startup installs nothing and does not launch providers, watchers, model downloads or private-engine wake/close procedures. Source code for those procedures is inspectable; their presence does not select or initialise personal state.

Human saving and delegated proposal/source application retain their existing owners and guards. Work within the user's authorised scope; retain exact inputs, outcomes and independent review evidence where the workflow requires them. Do not turn an old accepted review into a current one or substitute a narrative for an actual owner effect.

Keep test projects and newly generated outputs separate from the retained manuscripts and scientific records. Follow the behaviour tour for real examples and their observed limits. A package install or example fixture is not a claim that historical benchmarks were independently rerun.

When finishing work, preserve a concise result, exact checks and remaining work in this repository's appropriate record. Commit only the intended changes and state whether they were pushed. Keep user drafts, histories and unrelated source changes. Personal-engine publication or shared-state cleanup requires the user's applicable explicit instruction; it is not a default requirement of this portable application.
